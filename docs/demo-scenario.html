Сценарий демонстрации

Пошаговый показ лабораторных и продуктовых сценариев на эмуляторе. Полный сценарий — около 15 минут; сокращённая версия для защиты — на странице «Защита».

Подготовка (за 15 минут)

  1. ./tool/start_emulator.sh — поднимает эмулятор slotly_api36 и ждёт загрузки (или F5 в VS Code — то же плюс запуск приложения).
  2. flutter run -d emulator-5554 (для замеров и скриншотов — --profile).
  3. Для чистых демо-данных: adb shell pm clear kz.slotly.mobile перед запуском. Данные сохраняются между запусками, поэтому записи и отзывы с прошлой репетиции останутся, если не очистить.
  4. Во втором окне: adb logcat -s flutter. В браузере: docs/index.html, design/prototype/index.html.
  5. Логины — «Вход и роли»; на экране входа их можно подставить касанием.

Изоляция данных (whiteline / whiteline-demo)

Войти владельцем «Белой линии»: на дашборде и в записях — только клиника; данных «Северного» нет. Прямые вызовы запрещены — показать тест test/data/permission_enforcement_test.dart или интеграционный сценарий 6.

Завершение

Профиль → «Выйти» → подтверждение: Welcome, «Назад» не возвращает в кабинет. Перезапуск — снова Welcome.

Производительность

Замер — profile-сборка на эмуляторе, integration_test/perf_test.dart: время кадров из FrameTiming движка (build — код приложения на UI-потоке, raster — отрисовка).

СценарийКадровBuild p90 / p99 / худшийBuild > 16 мсRaster среднее / p90
Каталог, первый проход3911,5 / 536 / 536 мс4312 / 385 мс
Каталог, прокрутка1117,3 / 31,9 / 33,6 мс5272 / 391 мс
Организация: галерея и прокрутка1821,1 / 1,9 / 12,5 мс0135 / 414 мс
Дашборд: фильтры и прокрутка1961,0 / 4,2 / 13,9 мс038 / 37 мс
  • Build (код приложения) укладывается в бюджет 16,7 мс в галерее и на дашборде. В каталоге 4,5 % кадров прокрутки превышают бюджет (до 34 мс), а первый проход содержит 4 медленных кадра до 0,5 с — однократная стоимость первого построения и загрузки глифов. Это кандидат на оптимизацию, но на реальном устройстве не измерялось.
  • Raster на эмуляторе отражает его программную отрисовку: при запуске эмулятор сообщил «forcing software rendering for GLES». Эти цифры не переносятся на телефон с GPU. Лаги эмулятора и производительность приложения — разные вопросы; вывод о плавности на реальном телефоне можно сделать только после замера на нём.
  • Что уже сделано: ленивые списки (SliverList, ListView.builder), декодирование фото в размере показа (cacheWidth), уменьшение фото при выборе до 1600 px, кэш аналитики до изменения данных, запись базы в очереди без блокировки UI.

Повторить замер:

flutter drive --profile -d emulator-5554 \
  --driver=test_driver/perf_driver.dart \
  --target=integration_test/perf_test.dart
cat build/perf/frame_summary.json

Детерминированность

  • Время. Все репозитории и экраны получают Clock; в тестах «сейчас» — понедельник, 5 октября 2026, 09:00.
  • Данные. Seed с фиксированным зерном; TestData.create() даёт базу с каталогом без активности, withActivity: true — с полными демо-данными.
  • Внешние сервисы. Напоминания, выбор фото и файлы — фейки в памяти.
  • Golden. Шрифт FlutterTest, поверхность 360 × 780 при плотности 1, допуск 0,5 %. Эталоны обновляются только намеренно и после просмотра каждого изображения.

Как запускать

flutter test                                   # unit, widget, golden
flutter test --coverage && dart run tool/coverage_summary.dart
flutter test test/goldens                      # только golden
flutter test --update-goldens test/goldens     # обновить эталоны (осознанно)
./tool/start_emulator.sh                       # поднять эмулятор
flutter test integration_test/app_test.dart -d emulator-5554

Интеграционные тесты используют базу в памяти и не трогают данные установленного приложения.

Непрерывная интеграция

.github/workflows/flutter-ci.yml на push в main и на pull request: Java 17, Flutter 3.47.6, pub get, формат, анализ, flutter test --coverage, сводка покрытия, debug APK как артефакт; при падении golden — картинки различий. Интеграционные тесты в CI не запускаются (нужен эмулятор).

Цель «не менее 80 % для domain и data» выполнена. Ниже 80 % остаются только небольшие файлы, где не вызываются toString, == и hashCode (например, service.dart, time_slot.dart, gesture_point.dart) — отдельные тесты ради них не писались. Детерминированность

  • Время. Экраны и репозиторий получают Clock; в тестах «сейчас» — понедельник, 5 октября 2026, 09:00 (test/helpers/test_app.dart).
  • Размер экрана. Widget-тесты используют поверхность Pixel 7 (411 × 914 dp), golden — 360 × 780 при плотности 1.
  • Демо-расписание. Занятость слотов вычисляется формулой, а не случайно.
  • Шум в тестах распознавания. Random с фиксированным seed.
  • Шрифт golden. Встроенный тестовый шрифт FlutterTest; допуск 0,5 % пикселей на различия сглаживания macOS и Linux.

Как запускать

# всё, кроме интеграционного теста
flutter test

# покрытие
flutter test --coverage
dart run tool/coverage_summary.dart

# только golden; обновление эталонов — только намеренно
flutter test test/goldens
flutter test --update-goldens test/goldens

# интеграционный тест (нужен запущенный эмулятор или телефон)
flutter test integration_test -d emulator-5554

Интеграционный тест после прогона удаляет приложение с устройства — для дальнейшей демонстрации снова выполните flutter run.

Непрерывная интеграция

.github/workflows/flutter-ci.yml запускается на push в main и на каждый pull request: Java 17, Flutter 3.47.6 (кэш), pub get, проверка формата, flutter analyze, flutter test --coverage, сводка покрытия, сборка debug APK и загрузка его как артефакта. При падении golden-тестов загружаются картинки различий. continue-on-error не используется, эталоны в CI не обновляются.

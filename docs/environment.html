Состояние до подготовки

На машине изначально не было Flutter, Android SDK, подходящей JDK (была только Java 8 из браузерного плагина), GitHub CLI, Android Studio и VS Code. Установлены только компоненты, необходимые для Android-сборки. Глобальные системные пакеты не обновлялись, sudo не использовался.

Подготовка окружения с нуля (macOS)

# 1. Инструменты
brew install openjdk@17 gh
brew install --cask flutter android-commandlinetools

# 2. Android SDK (лицензии принимаются официальной командой)
export JAVA_HOME="$(brew --prefix openjdk@17)/libexec/openjdk.jdk/Contents/Home"
sdkmanager "platform-tools" "emulator" "platforms;android-36" \
  "build-tools;36.1.0" "system-images;android-36;google_apis;arm64-v8a"

# 3. Подключить SDK и JDK к Flutter
flutter config --android-sdk "$(brew --prefix)/share/android-commandlinetools" \
  --jdk-dir "$JAVA_HOME"
flutter doctor --android-licenses

# 4. Эмулятор
avdmanager create avd -n slotly_api36 \
  -k "system-images;android-36;google_apis;arm64-v8a" -d pixel_7
"$(brew --prefix)/share/android-commandlinetools/emulator/emulator" -avd slotly_api36

# 5. Проверка
flutter doctor -v
flutter devices

Редакторы

VS Code

В репозитории есть .vscode/extensions.json (рекомендует расширения Dart-Code.dart-code и Dart-Code.flutter), .vscode/settings.json (форматирование при сохранении, длина строки 80) и .vscode/launch.json (конфигурации debug и profile). На машине разработки VS Code не установлен, поэтому расширения не ставились автоматически. После установки VS Code откройте папку проекта и примите предложение установить рекомендуемые расширения.

Android Studio

Android Studio не требуется для сборки: всё выполняется через Flutter CLI и Gradle. Если участник хочет работать в Android Studio:

  1. Установить Android Studio с developer.android.com/studio или командой brew install --cask android-studio.
  2. Открыть Settings → Plugins → Marketplace, найти Flutter, нажать Install (плагин Dart установится вместе с ним) и перезапустить IDE.
  3. В Settings → Languages & Frameworks → Flutter указать путь к Flutter SDK (вывод flutter doctor -v, строка «Flutter version … at …»).
  4. Открыть корневую папку проекта (а не папку android/).

Аналитика владельца

Все показатели дашборда рассчитываются из записей, отзывов и избранного одной организации. Готовых чисел нет ни в коде, ни в базе.

Поток данных

  1. OwnerDashboardScreen запрашивает AnalyticsRepository.fetch(organizationId, period).
  2. LocalAnalyticsRepository проверяет право viewDashboard для этой организации и отбирает записи, отзывы и избранное только с её organizationId.
  3. AnalyticsCalculator.calculate — чистая функция без Flutter — возвращает OwnerAnalytics: все KPI и ряды для графиков.
  4. Результат кэшируется до следующего изменения данных (ревизия базы) и не дольше 5 минут, поэтому переключение периодов не пересчитывает ничего лишнего, а экран не считает на каждом кадре.

Формулы

Период N дней = с 00:00 дня «сегодня − (N − 1)» до текущего момента. Будущие записи не учитываются.

Графики

  • Динамика записей, новые отзывы, добавления в избранное — вертикальные столбцы одного ряда в фирменном цвете; касание столбца показывает точное значение над графиком (мобильный аналог подсказки при наведении).
  • Записи по специалистам и популярность услуг — горизонтальные полосы с подписью и числом; больше пяти пунктов сворачиваются в «Остальные».
  • Статусы — одна составная полоса и легенда, в которой каждое значение повторено текстом с процентом.
  • Каждый график имеет кнопку «Показать таблицей» — текстовую альтернативу. Для TalkBack у графика одна подпись: «Записи по дням: всего N, максимум M (дата)».
  • Одна ось, без двойных шкал; сетки нет, ось — только максимум и ноль.
  • Анимация столбцов — 200 мс и отключается системной настройкой «Убрать анимацию».

Цвета

Однорядные графики — основной цвет темы. Для трёх статусов — категориальные слоты синий, оранжевый, бирюзовый (светлая тема #2A78D6, #EB6834, #1BAF7A, тёмная #3987E5, #D95926, #199E70), фиксированные за статусом и не зависящие от того, какие статусы есть в периоде. Палитра проверена валидатором на различимость при дальтонизме: все пары проходят в обеих темах (минимальное ΔE при CVD 9,2 в светлой и 9,4 в тёмной). У бирюзового в светлой теме контраст с фоном ниже 3:1, поэтому значения всегда подписаны текстом и есть табличный вид. Первая версия палитры (бренд-бирюзовый, янтарный, серо-синий, розовый) проверку не прошла — серый и розовый сливались при протанопии — и была заменена.

Почему без библиотеки графиков

Все графики столбчатые, поэтому хватило двух небольших виджетов на Row/Container (lib/features/analytics/presentation/charts.dart). Они получают тёмную тему и Semantics без настройки и проверяются golden-тестами. fl_chart стоит подключить, когда понадобятся линейные графики с интерактивными подсказками и масштабированием по времени.

Тесты

  • test/features/analytics/analytics_calculator_test.dart — формулы на вручную составленных данных: счётчики и доля отмен, топ при равенстве, разбиение по дням и неделям, отзывы и избранное по дате создания, пустой период без деления на ноль, монотонность по периодам.
  • test/features/analytics/analytics_repository_test.dart — только данные своей организации, данные во всех периодах, кэш до изменения данных, запрет для чужого владельца.
  • Golden: дашборд в светлой и тёмной теме и пустое состояние; widget: фильтр периода и табличный вид; интеграционный сценарий 4.

Архитектура

Прагматичная feature-first структура: каждая функция приложения лежит в своей папке, общие части вынесены в app/ и core/. Слоёв ровно столько, сколько нужно для тестирования и будущей замены демо-данных на backend.

Экраны не создают свои источники данных и не знают о маршрутах друг друга. Например, CatalogScreen получает List<Service> и колбэк onServiceSelected, а куда вести пользователя, решает routes.dart. Поэтому каждый экран тестируется отдельно с любыми данными.

Правило: общие данные приложения живут в контроллерах, локальные данные одного экрана — в его State. BLoC, Riverpod и service locator не используются: для трёх общих объектов состояния стандартного ChangeNotifier достаточно.

Внедрение зависимостей

AppDependencies (lib/app/app_scope.dart) создаётся один раз в SlotlyApp и освобождается в его dispose. Это единственное место, где выбираются реализации:

factory AppDependencies.demo({Clock clock = systemClock}) {
  final bookings = BookingsController(InMemoryBookingRepository(clock: clock));
  unawaited(bookings.load());
  return AppDependencies(
    clock: clock,
    appController: AppController(),
    services: demoServices,
    lifecycleLogger: LifecycleLogger(clock: clock),
    bookings: bookings,
    tickets: const MockTicketRepository(),
    gestureClassifier: GestureClassifier(templates: symbolTemplates),
  );
}

AppScope — простой InheritedWidget, через который маршруты достают зависимости и передают их в конструкторы экранов. Тесты подставляют свою фабрику: SlotlyApp(createDependencies: createTestDependencies) с фиксированными часами.

Навигация

  • WelcomeScreen → pushReplacement → HomeShell.
  • HomeShell: один Scaffold, NavigationBar и IndexedStack с тремя вкладками.
  • Вложенные экраны открываются поверх оболочки через Navigator.push: AppRoutes.serviceDetails(service), AppRoutes.bookingForm(service) и именованные маршруты /diagnostics, /gesture-lab, /ticket-check-in.
  • Системная кнопка Back: на вложенном экране — закрывает его; на вкладке «Записи» или «Профиль» — возвращает на «Услуги»; на «Услугах» — закрывает приложение.

Сторонних runtime-пакетов нет. Форматирование дат и цен написано вручную (lib/core/utils/formatters.dart, около 60 строк) вместо intl; графика нарисована CustomPainter вместо flutter_svg; состояние — на ChangeNotifier вместо state-management библиотек. Точные версии транзитивных пакетов зафиксированы в pubspec.lock.

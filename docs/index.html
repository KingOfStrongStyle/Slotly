Slotly: документация проекта

Учебный MVP мобильного сервиса онлайн-записи и электронной очереди для локального бизнеса. Flutter + Dart, Android, Material 3.

Версия 0.1.0. Все проверки финальной сборки пройдены: формат, анализатор, 105 автоматических тестов, интеграционный тест на эмуляторе, debug- и release-сборка. Подробности — в разделе «Тестирование».

Быстрый старт

flutter pub get
flutter run                 # нужен запущенный эмулятор или телефон
flutter test                # все unit-, widget- и golden-тесты
open docs/index.html        # эта документация
open design/prototype/index.html   # интерактивный прототип

Все страницы — обычные HTML-файлы без внешних зависимостей и CDN; их можно открыть двойным щелчком или распечатать (есть стили для печати).

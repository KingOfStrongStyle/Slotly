## Что проверено

- `dart format`, `flutter analyze` — без замечаний.
- `flutter test` — 344 прогонов проходят; покрытие domain + data 94,9 %, весь `lib/` 93,4 %.
- 8 интеграционных сценариев — пройдены на эмуляторе Android 16 (API 36).
- Debug и release APK собираются; release запущен на эмуляторе.
- Ручные сценарии клиента и владельца, системный диалог уведомлений, доставка напоминания и переход по нему, Photo Picker и лимит фото — на эмуляторе.

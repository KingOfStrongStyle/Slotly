# Задачи проекта Slotly

Статус на 5 октября 2026 года, версия 0.1.0.

## Распределение зон ответственности

Трудоёмкость каждой зоны — условные 16 баллов (внутренняя оценка баланса, не прогноз оценки преподавателя). Зона означает ответственность за изучение, сопровождение и защиту модуля. Первичная реализация закоммичена владельцем репозитория; дальнейшие изменения каждый участник вносит от своего имени.

## Что проверено

- `dart format`, `flutter analyze` — без замечаний.
- `flutter test` — 105 тестов проходят; покрытие domain + data 92,8 %, весь `lib/` 95,6 %.
- Интеграционный тест — пройден на эмуляторе Android 16 (API 36).
- Debug и release APK собираются; release запущен на эмуляторе.
- Ручной сценарий всех лабораторных на эмуляторе, без исключений в консоли.
- Внутренние ссылки HTML-документации — без битых ссылок.

## Что осталось и требует участия владельца

- [ ] Опубликовать репозиторий в GitHub: нужна авторизация GitHub CLI (`gh auth login`), затем `gh repo create slotly-mobile --private --source=. --remote=origin --push` и `git push origin --tags`.
- [ ] После первого push убедиться, что workflow «Flutter CI» прошёл (в частности, golden-тесты на Linux с допуском 0,5 %).
- [ ] Пригласить Влада и Яна в репозиторий; при желании добавить `.github/CODEOWNERS`.
- [ ] Каждому участнику пройти чек-лист раздела 16 своей страницы в `docs/team/`.

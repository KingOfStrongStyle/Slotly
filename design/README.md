# Дизайн Slotly

## Где что лежит

| Путь | Назначение |
|---|---|
| `prototype/index.html` | интерактивный прототип: 8 фреймов, кликабельный основной сценарий, режим «все фреймы» |
| `prototype/ui-kit.html` | UI kit: цвета, типографика, отступы, радиусы, иконки, компоненты в состояниях, правила |
| `figma-import/frames/` | 8 SVG-фреймов для импорта в Figma |
| `figma-import/components/` | SVG-компоненты UI kit |
| `figma-import/README.md` | инструкция по импорту и связям прототипа в Figma |
| `assets/slotly-logo.svg` | логотип |
| `tools/build_prototype.py` | генератор всех файлов выше из токенов темы |

Открыть прототип: `open design/prototype/index.html` (macOS) или двойным щелчком по файлу. Сервер не нужен.

Пересобрать после изменения токенов или экранов: `python3 design/tools/build_prototype.py` (Python 3.9+, без сторонних пакетов).

# Дизайн-направление

Ответственный за сопровождение: **Ян** (UI kit, прототип, визуальные компоненты).

## Принципы

1. **Спокойный сервисный интерфейс.** Пользователь приходит записаться за минуту — экран не должен отвлекать.
2. **Material 3 без кастомизации ради кастомизации.** Все цвета выводятся из одного seed-цвета, компоненты — стандартные Material 3.
3. **Собственная графика.** Логотип и иллюстрации услуг — простые геометрические формы, нарисованные кодом (`CustomPainter`) и продублированные в SVG. Сетевые и сторонние изображения не используются.
4. **Одинаковые токены в приложении и прототипе.** Значения ниже сняты с `ColorScheme.fromSeed` во Flutter (`lib/app/theme.dart`), а не подобраны вручную.

## Цвета (светлая схема)

| Токен | Значение | Применение |
|---|---|---|
| seed | `#0B6E69` | исходный цвет бренда |
| primary | `#006A65` | основные кнопки, выбранные элементы |
| onPrimary | `#FFFFFF` | текст на primary |
| primaryContainer | `#9DF2EA` | выбранный слот, активная вкладка |
| onPrimaryContainer | `#00504C` | текст на primaryContainer |
| secondaryContainer | `#CCE8E5` | индикатор NavigationBar, чипы |
| tertiaryContainer | `#D0E4FF` | акцент иллюстраций |
| error | `#BA1A1A` | ошибки, отмена записи |
| errorContainer | `#FFDAD6` | фон сообщений об ошибке |
| surface | `#F4FBF9` | фон экранов |
| surfaceContainerLow | `#EFF5F3` | фон карточек |
| surfaceContainerHighest | `#DDE4E2` | поля ввода |
| onSurface | `#161D1C` | основной текст |
| onSurfaceVariant | `#3F4947` | вторичный текст |
| outlineVariant | `#BEC9C7` | границы карточек, разделители |

Тёмная схема генерируется из того же seed (`Brightness.dark`).

## Типографика

Шрифт системы Android (Roboto), шкала Material 3:

| Роль | Размер / интерлиньяж | Где используется |
|---|---|---|
| headlineMedium | 28 / 36 | заголовок welcome |
| titleLarge | 22 / 28 | заголовки экранов |
| titleMedium | 16 / 24, 500 | названия услуг |
| bodyLarge | 16 / 24 | основной текст |
| bodyMedium | 14 / 20 | описания, подписи |
| labelLarge | 14 / 20, 500 | кнопки, чипы |
| bodySmall | 12 / 16 | метаданные, журнал событий |

## Отступы и радиусы

- Шкала отступов: 4, 8, 12, 16, 24, 32 dp (`AppSpacing`).
- Радиусы: 8 (чипы), 12 (кнопки, поля), 16 (карточки), 28 (диалоги) (`AppRadii`).
- Минимальная зона касания: 48 × 48 dp.
- Максимальная ширина контента на планшете: 640 dp.

## Иконки

Material Symbols из Flutter SDK (`Icons.*`), стиль outlined для неактивных и filled для активных состояний навигации.

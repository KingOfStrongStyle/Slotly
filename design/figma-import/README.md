# Импорт дизайна Slotly в Figma

Прямого доступа к Figma при подготовке проекта не было, поэтому ссылка на Figma-файл не создавалась. Вместо этого подготовлены SVG-файлы, которые импортируются в Figma без потерь основной структуры.

## Состав

| Папка | Файлы | Что внутри |
|---|---|---|
| `frames/` | `01-welcome.svg` … `11-dashboard.svg` | 11 мобильных фреймов 360 × 800: сценарий клиента и обзор владельца |
| `components/` | `button.svg`, `chip.svg`, `time-slot.svg`, `service-card.svg`, `text-field.svg`, `navigation-bar.svg` | компоненты UI kit в состояниях default / pressed / disabled / error |
| `../assets/slotly-logo.svg` | — | логотип |

Файлы генерируются скриптом `design/tools/build_prototype.py` из тех же токенов, что и тема Flutter (`lib/app/theme.dart`).

## Как импортировать

1. Откройте Figma и создайте новый Design-файл «Slotly».
2. Перетащите все файлы из `frames/` на холст (или *Main menu → File → Import…* / <kbd>Cmd/Ctrl + Shift + K</kbd>). Каждый SVG станет отдельным фреймом 360 × 800.
3. Расположите фреймы в ряд по номерам: Welcome → Каталог → Результаты поиска → Детали → Специалист и время → Подтверждение → Мои записи → Профиль.
4. Импортируйте файлы из `components/` на отдельную страницу «UI kit». Выделите каждый компонент и нажмите *Create component* (<kbd>Cmd/Ctrl + Alt + K</kbd>), чтобы получить переиспользуемые компоненты.
5. Создайте цветовые стили по таблице из `design/README.md` или `design/prototype/ui-kit.html` (*Local styles → Color styles*).
6. Шрифт в SVG — Roboto. Если он не установлен, Figma предложит замену: выберите Roboto из Google Fonts в самой Figma.

## Кликабельный прототип в Figma

Готовый кликабельный сценарий уже есть в браузере: `design/prototype/index.html`. Чтобы повторить его в Figma:

1. Перейдите на вкладку *Prototype*.
2. Соедините элементы по таблице (триггер *On tap*, действие *Navigate to*, анимация *Smart animate* или *Instant*):

| Фрейм | Элемент | Переход |
|---|---|---|
| 01 Welcome | «Продолжить» | 02 Вход |
| 02 Вход | «Войти», демо-аккаунты клиентов | 03 Каталог мест |
| 02 Вход | демо-аккаунт владельца | 11 Обзор владельца |
| 03 Каталог мест | поле поиска, сегмент «Услуги» | 04 Поиск услуг |
| 04 Поиск услуг | сегмент «Места» | 03 Каталог мест |
| 03 Каталог мест | карточка «Северного» | 05 Организация |
| 05 Организация | «Мужская стрижка» | 06 Детали услуги |
| 04 Поиск услуг | карточка «Мужская стрижка» | 06 Детали услуги |
| 06 Детали | «Записаться» | 07 Вариант, специалист и время |
| 07 | «Продолжить» | 08 Подтверждение |
| 08 Подтверждение | «Подтвердить» / «Изменить» | 09 Мои записи / 07 |
| 03, 04, 09, 10 | вкладки нижней навигации | 03 / 09 / 10 |
| 10 Профиль, 11 Обзор | «Выйти» / «Организация» | 01 Welcome |
| 02, 05, 06, 07 | стрелка «назад» | предыдущий фрейм |

3. Укажите 01 Welcome как стартовый фрейм (*Flow starting point*) и запустите *Present*.

Прозрачные прямоугольники с атрибутом `data-hotspot` в SVG — это кликабельные зоны HTML-прототипа. В Figma их можно удалить или использовать как области для связей.
